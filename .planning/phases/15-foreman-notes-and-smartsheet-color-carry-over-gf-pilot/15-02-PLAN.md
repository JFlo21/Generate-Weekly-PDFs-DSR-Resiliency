## Interface contract (later plans depend on these exact names)

- `NOTES_KEY = 'Foreman Notes'`; `STYLE_KEY = '__fn_style'`.
- `STYLE_COLUMNS`: ordered tuple of `(excel_column_number, logical_column_name)`:
  `(1,'Pole #')`, `(2,'CU')`, `(3,'Work Type')`, `(4,'CU Description')`, `(5,'Unit of Measure')`,
  `(6,'Quantity')`, `(8,'Units Total Price')`, `(9,'Foreman Notes')`. Column 7 ("N/A") is never
  styled. Column 9 is included because the CONTEXT domain says every CU-line column sourced from
  Smartsheet carries its colour and column I is sourced from the `Foreman Notes` cell (Claude's
  discretion reading of D-15-10; with today's row-level rules it simply receives the row colour).
- `compute_effective_scope(configured, *, test_mode, upload_enabled, memory_write_possible) -> str`
  (pure). `memory_writes_possible() -> bool` reads the config flags that gate pipeline_memory /
  hash-store writes (`SUPABASE_HASH_STORE_WRITE_ENABLED`, `RUN_MEMORY_WRITE_ENABLED and not
  TEST_MODE`, plus any further write flag 15-05 Task 2 finds). `EFFECTIVE_SCOPE` = the scope
  function applied to config at import (SKIP_UPLOAD is deliberately NOT an input).
- `is_dry_run_pilot() -> bool` (EFFECTIVE_SCOPE != 'off' and TEST_MODE and not upload_enabled);
  `memory_write_blocked(kind: str) -> bool` returns True when `is_dry_run_pilot()`; it is called
  only INSIDE an existing write gate (i.e. only when that gate would have let the write run), so
  it signals a write that was actually reached; it logs ERROR at most once per kind per run (a
  module-level set of logged kinds, cleared by `reset_state()`), naming only `kind`.
- `mapping_enabled() -> bool`; `mapping_schema_marker(base: str) -> str`.
- `FnState` (frozen dataclass: `scope: str`, `allowlist: frozenset[str]`, `pilot_wrs:
  frozenset[str]`, `gf_loaded: bool`); `set_state`, `get_state`, `reset_state`; default state is
  scope `off`.
- `initialize(client) -> FnState` (never raises).
- `is_pilot_row(row) -> bool`, `is_pilot_group(rows) -> bool`.
- `norm_note(value) -> str`.
- `row_notes_component(row) -> str | None`; `group_notes_token(sorted_rows, row_identity) -> str`;
  `globals_component() -> str`.
- `parse_descriptor(desc)`, `resolve_cell_style(cell_cf, row_cf, cell_fmt, row_fmt) ->
  tuple[str | None, str | None]` as `(fill_hex, font_hex)`.
- `build_sheet_column_maps(source_sheets) -> dict[int, dict[str, int]]`;
  `attach_group_styles(client, group_rows, sheet_maps) -> int`; `reset_style_cache()`.
