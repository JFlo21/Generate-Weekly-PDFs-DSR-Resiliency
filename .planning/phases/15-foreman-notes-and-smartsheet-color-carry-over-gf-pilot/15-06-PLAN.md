## Dry-run recipe (single source; every doc below copies it verbatim)

`TEST_MODE=true SKIP_UPLOAD=true WR_FILTER=<pilot WR> RUN_MEMORY_WRITE_ENABLED=0 SUPABASE_HASH_STORE_WRITE_ENABLED=0 PYTHONUTF8=1 python generate_weekly_pdfs.py`
with the token exported in the operator's own shell and `FOREMAN_NOTES_PILOT_GFS` set to the real pilot GF names in the operator's local `.env` (loaded by the facade's `load_dotenv()`; never committed). With it unset there are zero pilot groups. `WR_FILTER` is honoured only with TEST_MODE
(run-billing-pipeline-locally skill). If any pipeline_memory write flag is left on, the effective
scope falls back to off (one WARNING) and the files look like today's - that is the no-persist
guard, not a bug. SKIP_UPLOAD alone never renders pilot output.
