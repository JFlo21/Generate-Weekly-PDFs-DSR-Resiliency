<objective>
Fix 1 of Phase 11.1: cut the discovery phase from ~67 minutes back to low
single-digit minutes by skipping full per-sheet validation for candidate
sheets whose live Smartsheet version still matches the version recorded in
`pipeline_memory.sheet_registry`, reusing the stored `column_mapping`.

Purpose: run 33512477875 spent 4008.6s (66.8 min) re-validating all 121
candidate sheets because INC-05 retired the discovery cache. `sheet_registry`
already holds the cross-run identity that cache used to hold — this plan reads
it instead of re-deriving it, while keeping "any doubt -> full validation"
absolutely intact (D-11.1-01).

Output: a never-raising `_build_discovery_skip_index` helper, a pure
side-effect-free fast path at the top of `_validate_single_sheet`, one extra
selected column in `get_sheet_watermarks`, an operator-visible validation
split log line, and two new unit-test classes covering the happy path and the
full doubt-branch matrix.
</objective>

## Trust Boundaries

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
