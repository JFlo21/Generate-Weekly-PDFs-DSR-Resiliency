## Shared Patterns

### Retry wrapper for all new SDK calls
**Source:** `pipeline/retry.py:158-198` (`smartsheet_call_with_retry`), already imported in both `pipeline/discovery.py:46` and `pipeline/orchestrate.py:59`.
**Apply to:** the new `list_sheets(...)` bulk version probe (Fix 1) and the new `list_all_attachments(...)` bulk listing calls (Fix 2) — both must be wrapped exactly like every other Smartsheet call in these two files, e.g.:
```python
sheet = smartsheet_call_with_retry(
    client.Sheets.get_sheet, sid, include='columns',
    label=f"validate sheet {sid}",
)
```
Never hand-roll a second retry loop (RESEARCH.md "Don't Hand-Roll").

### Fail-open / fail-closed exception boundary discipline
**Source:** `pipeline_memory/reader.py:1-9` (module docstring, fail-open contract) + `pipeline/discovery.py:514-529` and `:555-571` (fail-closed guard).
**Apply to:** both fixes' new one-time bulk-probe calls. A probe/read failure must degrade to "no data for this sid" (dict-miss semantics), which the existing per-sheet / per-row code already treats as "do the expensive thing" — never let a probe failure raise into, or otherwise touch, `_failed_validation_sids` (Fix 1) or bypass `_live_row_attachments`'s own `except Exception: return None` (Fix 2, unchanged).

### Sentry span instrumentation for new bulk operations
**Source:** `pipeline/orchestrate.py:2780-2783` (`sentry_sdk.start_span(op="pipeline_memory.group_state_attachments", name="Resolve attachment identity from group_state")`).
**Apply to:** the new Fix 2 bulk-listing block (and optionally Fix 1's bulk version probe) — same `op`/`name` telemetry pattern, consistent with this file's existing instrumentation density around the group loop.

### "Pre-fetched-list-over-live-call" parameter idiom
**Source:** `pipeline/cleanup.py:481,494,511` (`delete_old_excel_attachments`'s `cached_attachments: list | None = None`).
**Apply to:** conceptual precedent only — Fix 2 does not add a new parameter (it pre-seeds an existing module-level dict), but this is the established codebase idiom the planner should cite as prior art when justifying the "don't rewire call sites" design decision.
