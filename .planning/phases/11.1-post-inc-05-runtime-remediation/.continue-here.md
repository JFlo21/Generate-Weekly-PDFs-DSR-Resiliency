## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Codex-path gsd-tools | The pause/verify shim loops through `.codex` paths; using one is a harness-boundary violation | blocking | Call `node ~/.claude/gsd-core/bin/gsd-tools.cjs` directly |
| Job time as SC-1 | Reading the Actions job duration as the pipeline wall clock | blocking | Read `Duration` from the Python session log; compare step end time vs last INFO line if they differ by more than the post-job reserve |
| Unbounded child-process reads in tests | A subprocess test that `readline()`s a pipe hangs the whole pytest run when the child hangs at exit (this is exactly the INC-06 shape) | advisory | Use `communicate(timeout=…)` and kill the child on every path (`tests/test_inc06_parity_exit_hang.py`) |
| Bash heredoc python scripts | `<<'EOF'` python bodies with mixed quotes fail to parse in this tool | advisory | Write the script to the scratchpad with the Write tool and run `python <path>` |
| CRLF edits | Exact-string edit scripts fail on CRLF repo files | advisory | Normalize `\r\n`→`\n` on read and restore on write (see scratchpad `apply_*.py` helpers) |
| Placeholder grep as false-completion scan | `grep placeholder|TBD` matches ~48 planning files because "placeholder" is a domain term (sentinel files) | advisory | Do not treat those matches as incomplete summaries without reading them |

**Severity values:** `blocking` — resuming agent must pass understanding check before proceeding. `advisory` — important context, does not gate resumption.
