## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| CRLF golden refreeze | Regenerating `tests/golden/mypy_baseline.txt` on Windows writes CRLF; `test_golden_txt_baselines_contain_no_crlf` fails the suite | advisory | After any refreeze run `sed -i 's/\r$//'` on the golden file and re-run the gates |
| Piped exit-code masking | `cmd \| tail` returns tail's exit status — a failing gates run looked ambiguous | advisory | Redirect to a file and `echo $?`; never pipe a gate command |
