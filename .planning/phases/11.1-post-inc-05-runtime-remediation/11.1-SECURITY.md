## Trust Boundaries
| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| pipeline → Smartsheet API (sheet list / versions) | Untrusted external response feeds the discovery validation-skip decision that gates billing input completeness | Sheet ids, versions |
| pipeline → Supabase `pipeline_memory.sheet_registry` | Stored `name`, `column_mapping`, `last_sheet_version` cross back in and, on a version match, replace live column derivation | Column mappings |
| pipeline → Smartsheet Attachments API | Untrusted bulk listing crosses into the skip gate's existence decision (regenerate vs skip a billing Excel) | Attachment ids, parent ids |
| `group_state` stubs → skip gate | PR #373 boundary: identity stubs must never satisfy an existence check | Attachment identity |
| pipeline → Smartsheet API (sheet column metadata) | The plan 04 change narrows which slice of the `Sheet` response is requested; the column set must not narrow | Column metadata, 3 sample rows |
| `lookup_attribution_bulk` prefetch → in-run frozen-row cache | Plan 03 seeds the billing-audit row cache from a prior read; a wrong seed could skip a freeze | Frozen-row keys |
