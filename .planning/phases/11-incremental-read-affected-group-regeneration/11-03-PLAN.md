<objective>
Close CONTEXT.md D-06 before anything can produce a scoped `groups` dict. Three end-of-run
maintenance blocks in `pipeline/orchestrate.py` build their "what is still live" set
directly from `groups.items()` and delete everything absent from it: the `valid_wr_weeks`
builder feeding both `cleanup_untracked_sheet_attachments` call sites, and the
hash-history stale-key prune. Those blocks were written when `groups` always meant "every
currently valid group". Plan 04 breaks that invariant.

Purpose: this is the phase's dominant risk. Without these gates, the first incremental run
deletes live Smartsheet billing attachments and hash-history entries for every untouched
Work Request — silently, with no error and no operator signal. RESEARCH.md rates it the
single highest-severity finding of the phase.

Output: an existing-gate extension in each case, never new skip logic — `keep_historical`
threaded to the cleanup call boundary, and the prune's existing time-budget guard widened.
Landing these before plan 04 means the producer of a scoped `groups` arrives to a codebase
that is already safe.
</objective>

| Pipeline → Smartsheet attachment delete API | Delete calls cross into production billing artifacts; there is no undo. |
