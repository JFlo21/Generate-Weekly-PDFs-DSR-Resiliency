## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Smartsheet cell content → `pipeline_memory` NUMERIC columns | Untrusted, operator-authored cell text (currency symbols, unit suffixes, formulas) crosses into typed Postgres columns via PostgREST. |
| Python process → Supabase `service_role` client | The `pipeline_memory` writer holds a service-role key; every write crosses this boundary. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-11-01 | Tampering | `_row_to_payload` → `upsert_rows_bulk` NUMERIC cast | high | mitigate | Task 1: parse `Quantity` / `Units Total Price` in the caller with the engine's own `_parse_quantity` / `parse_price`; an unparseable value becomes NULL, never a raw string that fails the cast and drops a 500-row chunk under fail-open. |
| T-11-02 | Repudiation | `run_ledger` finish row | medium | mitigate | Task 2: populate `sheets_changed` on both the success and failure path so a run's own record of how much it saw is complete and cannot be silently understated. |
