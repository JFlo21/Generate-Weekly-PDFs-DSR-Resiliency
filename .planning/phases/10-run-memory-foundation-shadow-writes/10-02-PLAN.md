<objective>
Write the pipeline's per-row current state and change history into
`pipeline_memory.row_state` / `row_event` on every run, in bulk, fail-open, and
without touching what the run produces.

Purpose: MEM-02 (one row per Smartsheet `(sheet_id, row_id)`; a `row_event` ONLY
when the content hash changed; the personnel values observed at that time) and
MEM-03 (bulk, fail-open, shadow-mode). This is the ~208k-row path the tracer in
plan 10-01 proved the stack for.

Output: the hash/payload/bulk-upsert half of `pipeline_memory/writer.py`, one
additive field capture in `pipeline/fetch.py`, a budgeted per-sheet write loop in
`pipeline/orchestrate.py`, and the MEM-02 regression tests.
</objective>
