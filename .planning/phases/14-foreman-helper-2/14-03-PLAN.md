<objective>
Make attribution Helper #2-aware on the Python side only — and close the single most dangerous
silent-drop this phase can create: `freeze_row`'s all-sentinel short-circuit, which would classify a
Helper #2-only row as having no real claimer and never call the freeze RPC at all, with no error and
no distinguishable log.

Purpose: Excel generation does not depend on the freeze RPC succeeding, so this defect is invisible
to every "did a file get produced" check. It has to be closed by a test that constructs the exact
shape — Helper #2 real, everything else sentinel — and asserts the RPC WAS invoked.

Output: a Helper #2 claimant in the freeze payload, a fourth member in the all-sentinel gate, a
Helper #2 role in `ROLE_BY_VARIANT`/`resolve_claimer`, and a forward-compatible degrade for the
period before the Supabase migration in plan 14-09 lands.
</objective>
